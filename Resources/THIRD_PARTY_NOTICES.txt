YouPull - third-party components
=================================

YouPull invokes the following programs as separate helper executables.

1. yt-dlp
   Project: https://github.com/yt-dlp/yt-dlp
   YouPull bundles the official `yt-dlp_macos` standalone release executable.
   The yt-dlp source repository is primarily Unlicense, but the official
   PyInstaller-based macOS release contains third-party components and the
   combined release executable is distributed under GPLv3+ terms as documented
   by yt-dlp. Copies of LICENSE and THIRD_PARTY_LICENSES.txt are included after
   running scripts/fetch-standalone-tools.sh.

2. FFmpeg / FFprobe binaries distributed by ffmpeg-static
   Project: https://github.com/eugeneware/ffmpeg-static
   FFmpeg project: https://ffmpeg.org/
   Release used by YouPull 1.3: b6.1.1
   Architecture-specific license and build information are included in
   Resources/licenses/ffmpeg-static/ after fetching the standalone tools.

YouPull launches these helpers as separate processes; it does not link against
FFmpeg or yt-dlp libraries. If you redistribute a built YouPull.app, keep these
notices and the bundled license files with the application and comply with the
corresponding third-party licenses.
